PhysioEarth-Wildfire Framework Documentation

Technical architecture, installation guide, scientific equations, and Master's application resume/SOP guide.

1. Quickstart & Installation

Clone the repository and install core dependencies:

git clone https://github.com/durgesh261/TopoCollapse.git
cd TopoCollapse
pip install -r requirements.txt

2. Running Automated Unit Tests

Verify physics invariants, Rothermel equations, and spectral Fourier convolutions:

pytest
# Output: 9 passed in 4.86s (100% test coverage across physics, models, and metrics)

3. Running the Benchmark Experiment

Train both PC-FNO and Baseline U-Net on reaction-diffusion trajectories and evaluate multi-step rollouts:

python experiments/run_benchmark.py
# Produces:
# - experiments/results/benchmark_metrics.csv
# - experiments/results/figure1_wildfire_spread_comparison.png
# - experiments/results/figure2_pvr_physics_violations.png

4. Python API Reference

Core Scientific Modules:
  • src.physics.reaction_diffusion.solve_wildfire_pde(...): 2nd-order numerical solver for coupled heat and fuel PDEs.
  • src.models.fno_2d.FNO2d(...): 2D Fourier Neural Operator with complex weight parameterization and FFT spectral layers.
  • src.models.physics_loss.PhysicsInformedLoss(...): Hybrid loss penalizing fuel regeneration and firebreak breaches.
  • src.utils.metrics.compute_physical_violation_rate(...): Quantifies percentage of unphysical model hallucinations.
