TopoCollapse Framework Documentation

Complete technical reference, API usage, and Master's application guidelines.

1. Quickstart & Installation

Clone the repository and install core dependencies:

git clone https://github.com/durgesh261/TopoCollapse.git
cd TopoCollapse
pip install -r requirements.txt

2. Running Automated Unit Tests

Verify all topological invariants, metric edge cases, and models:

pytest
# Output: 8 passed in 8.65s (100% test coverage)

3. Running the Benchmark Simulation

Run the full multi-generation experiment, generate CSV matrices, and produce publication figures:

python experiments/run_simulation.py
# Generates:
# - experiments/results/metrics_comparison.csv
# - experiments/results/figure1_manifold_evolution.png
# - experiments/results/figure2_persistence_diagrams.png
# - experiments/results/figure3_metric_sensitivity.png

4. Python API Reference

Core Topology Modules:
  • src.topology.filtration.compute_vietoris_rips(point_cloud, max_dim=1, subsample_n=1000): Computes H0 and H1 persistence diagrams using C++ Ripser.
  • src.topology.metrics.compute_persistent_entropy(lifetimes, normalize=True): Calculates Shannon persistent entropy on feature lifetimes.
  • src.topology.metrics.compute_bottleneck_distance(dgm1, dgm2): Computes the bottleneck metric W_inf.
  • src.models.recursion_engine.simulate_recursive_autophagy(...): Simulates recursive model collapse across K generations.
