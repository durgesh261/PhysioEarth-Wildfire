> **Research Premise:** When generative models are trained recursively on synthetic data ($Gen_0 \to Gen_1 \dots \to Gen_K$), their distributions experience **Model Collapse (Autophagy)**. Standard Gaussian moment distances (such as Fréchet Inception Distance / FID) fail to detect geometric cavity erosion in early generations. **TopoCollapse** introduces a Vietoris-Rips Persistent Homology framework that diagnoses topological feature atrophy and tail diversity loss before distribution metrics trigger alarms.

## 🔬 Key Research Findings

In our empirical benchmarks simulating recursive model autophagy across 6 generations ($Gen_0 \to Gen_5$):
* **H1 Topological Persistence Atrophy:** The total $H_1$ loop persistence decays by **26.3%** ($\Sigma l_{H_1}: 1.916 \to 1.411$) and maximum feature lifespan shrinks from $0.671 \to 0.536$.
* **Homological Bottleneck Expansion:** The Bottleneck Distance $W_\infty$ to the ground-truth manifold surges by **+177%** ($0.074 \to 0.205$).
* **Blindness of Classical Baselines:** Across the same trajectory, Gaussian **Fréchet Distance remains virtually flat** ($0.0021 \to 0.0036$), completely missing the erosion of non-convex manifold cavities and low-density boundaries.

## 📐 Mathematical Formulation

Given a dataset or latent embedding representation $X = \{x_1, \dots, x_N\} \subset \mathbb{R}^D$ sampled from a generative model at generation $g$:

### 1. Vietoris-Rips Filtration $\mathcal{VR}(X, \epsilon)$
A $k$-simplex $\sigma = [x_0, \dots, x_k]$ belongs to the simplicial complex $\mathcal{VR}_\epsilon(X)$ if and only if the pairwise Euclidean distances satisfy:
$$\forall i, j \in \{0, \dots, k\}, \quad \|x_i - x_j\|_2 \le \epsilon$$

### 2. Persistent Homology Groups & Lifetimes
We track the birth ($\alpha_b$) and death ($\alpha_d$) of homology classes across increasing scale $\epsilon$:
$$H_k(\mathcal{VR}_\epsilon(X)), \quad \text{where } k=0 \text{ (connected components)}, \quad k=1 \text{ (1D loops / tunnels)}$$
The persistence lifetime of the $i$-th feature is defined as:
$$l_i = \alpha_d^{(i)} - \alpha_b^{(i)}$$

### 3. Persistent Entropy
To measure the structural heterogeneity and dispersion of topological features, we compute the normalized persistent entropy:
$$E(D) = -\sum_{i=1}^M p_i \log_2(p_i), \quad \text{where } p_i = \frac{l_i}{\sum_{j=1}^M l_j}, \quad E_{\text{norm}} = \frac{E(D)}{\log_2(M)}$$

### 4. Diagram Distances
To quantify geometric deformation away from the true manifold diagram $D_0$:
* **Bottleneck Distance:**
  $$W_\infty(D_0, D_g) = \inf_{\gamma} \sup_{x \in D_0} \|x - \gamma(x)\|_\infty$$
* **$p$-Wasserstein Distance:**
  $$W_p(D_0, D_g) = \left( \inf_{\gamma} \sum_{x \in D_0} \|x - \gamma(x)\|_\infty^p \right)^{1/p}$$

## 🚀 Quick Start

### 1. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/your-username/topocollapse.git
cd topocollapse
pip install -r requirements.txt
```

### 2. Run Automated Unit Tests
Verify all topological invariants, metric edge cases, and models:
```bash
pytest
```
*Output: `8 passed in 8.65s` (100% test coverage for filtration, persistence metrics, and models).*

### 3. Run the Benchmark Simulation
Execute the full pipeline, generate quantitative matrices, and export publication figures:
```bash
python experiments/run_simulation.py
```
All generated figures and the metrics CSV will appear in `experiments/results/`.

### 4. Launch the Interactive Web Dashboard
Explore manifold evolution and persistence diagrams with live controls and generation playback:
```bash
python dashboard/serve.py
```
*Launches the dashboard at `http://localhost:8000/index.html` with interactive canvas visualizers and real-time metric HUDs.*
